## Para el equipo: cómo calcular el SUS

1. En las frases impares (1, 3, 5, 7, 9) se resta 1 a la respuesta.
2. En las frases pares (2, 4, 6, 8, 10) se resta la respuesta a 5.
3. Se suman los diez valores y el total se multiplica por 2,5. El resultado va de 0 a 100.

Ejemplo: respuestas 4, 2, 5, 1, 4, 2, 5, 1, 4, 2 dan (3+3+4+4+3+3+4+4+3+3) × 2,5 = 85.

En `resultados.csv` se anotan las diez respuestas tal como las marcó el participante, y el puntaje
SUS ya calculado.
