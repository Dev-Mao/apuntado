# Evidencias de la validación

Una carpeta por participante, con este contenido:

```
U01/
  mesa.png              captura de la partida en curso
  rechazo-cierre.png    el mensaje del sistema en la tarea T4
  final.png             la pantalla de fin de partida
  observacion.pdf       la hoja de observación llena (foto o escaneo)
  cuestionario.pdf      el cuestionario respondido
  bitacora.csv          el log de sus partidas (consulta 4 de consultas-bitacora.sql)
  grabacion.md          el enlace al video (Drive o YouTube no listado)
```

Antes de subir, tapar nombres reales, caras y notificaciones personales. Los videos no se suben al
repositorio, solo su enlace.
